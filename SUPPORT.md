# Support

## How to get help

- **[FAQ](docs/faq.md)** — answers to common questions and troubleshooting tips.
- **[Documentation](docs/README.md)** — complete documentation index: installation, configuration, sync modes, p2p mode, and more.
- **[GitHub Issues](https://github.com/albertsdk/hsync-client/issues)** — bug reports and feature requests. Please search existing issues before opening a new one.
- **[GitHub Discussions](https://github.com/albertsdk/hsync-client/discussions)** — community questions, ideas, and general discussion.
- **[Security Policy](SECURITY.md)** — how to report security vulnerabilities privately.

## Before asking for help

1. Check the [FAQ](docs/faq.md) — your question may already be answered.
2. Check the [documentation](docs/README.md) — the installation, configuration, and usage guides cover common issues.
3. Run with verbose output (`-v`) to see detailed log messages.
4. Verify your configuration: `HSYNC_SERVER` and `HSYNC_API_KEY` must be set (Server Mode), or `hsync p2p` with a reachable p2p peer.

## 💚 Solo project

HSYNC is a passion project maintained in spare time by volunteers. Feature requests, bug reports, and pull requests are reviewed as soon as possible, but response times may vary. Thank you for your patience and support!
